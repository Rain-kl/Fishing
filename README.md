# Fishing SSH 蜜罐平台

Fishing 是一个基于 Go 语言与嵌入式静态前端构建的轻量级 SSH 蜜罐平台。用户可通过控制台创建、启停并管理仿真 SSH 蜜罐实例，进入具体蜜罐详情页查看该实例的访问与命令日志，并支持导出下载审计记录。

## 核心能力

- **SSH 蜜罐管理**：在控制台选择蜜罐类型（当前版本支持 SSH）、监听端口、登录用户名与密码即可即时创建并启动监听；支持启停与删除操作，配置持久化存储于数据目录。
- **详情审计与日志导出**：首页仅展示平台概览与蜜罐实例列表；点击具体蜜罐名称或「`[进入详情]`」后可查看该蜜罐专属访问来源 IP、认证尝试凭据与命令记录，支持按事件与关键词筛选，并可导出下载 `JSONL` 或 `CSV` 格式日志文件。
- **纯内存 SSH 仿真**：内置内存虚拟文件系统与常规 Linux 响应（`id`、`whoami`、`uname`、`pwd`、`cd`、`ls`、`cat`、`ps`、`ip`、`ss`、`df`、`free`、`uptime`、`history` 等），不调用宿主机系统命令、不读取宿主机文件、不发起外部网络请求且禁用端口转发。

## 快速启动

### 本地源码运行

```bash
go run . -addr :8080 -data-dir ./data -bind-host 0.0.0.0
```

启动后访问 `http://127.0.0.1:8080` 进入控制台界面。点击「`[+ 添加蜜罐]`」，填写端口（例如 `2222`）、用户名与密码后提交即可完成创建并开始监听；点击列表中具体蜜罐即可进入详情页审计与导出日志。

### 使用 Docker Compose 运行

```bash
docker compose up -d --build
```

默认配置启用只读根文件系统（`read_only: true`）、移除全部内核能力（`cap_drop: ALL`）并以非 root 用户 `10001:10001` 运行；数据通过命名卷 `fishing-data` 持久化于 `/data`。因非 root 进程不能直接绑定容器内 `1024` 以下特权端口，如需对外暴露 `22` 端口，可在 `ports` 中配置宿主机端口转发（例如 `"22:2222"`）。若改用宿主机目录挂载 `./data:/data`，请提前设置目录权限：

```bash
mkdir -p ./data && chown -R 10001:10001 ./data
```

使用已发布的 GHCR 镜像时，可通过环境变量指定镜像地址：

```bash
FISHING_IMAGE=ghcr.io/<owner>/fishing:latest docker compose up -d
```

## 运行参数与环境变量

| CLI 参数 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `-addr` | `FISHING_ADDR` | `:8080` | Web 控制台与 HTTP API 监听地址 |
| `-data-dir` | `FISHING_DATA_DIR` | `./data` | 配置文件、SSH 宿主密钥与审计日志存储目录 |
| `-bind-host` | `FISHING_BIND_HOST` | `0.0.0.0` | SSH 蜜罐实例监听绑定的主机地址 |
